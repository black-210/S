# RIPOSTE — Rust Development Integration

## Supported Components
- `rustc`: Rust Compiler
- `cargo`: Package and build manager
- `rust-analyzer`: Official Language Server Protocol implementation
- `clippy-driver`: Static linter for idiomatic Rust code
- `rustfmt`: Code formatter

## Commands
- `RIPOSTE: Cargo Check`: Fast workspace syntax and type validation
- `RIPOSTE: Cargo Build`: Compiles workspace binaries and libraries
- `RIPOSTE: Cargo Test`: Executes unit and integration tests
- `RIPOSTE AI: Explain Rust Diagnostic`: Instant AI explanations for Rust ownership, lifetime (`E0382`, `E0502`), and trait bound errors
