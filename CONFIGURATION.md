# RIPOSTE — Configuration Settings

- `riposte.gemini.apiKey`: Gemini API key
- `riposte.gemini.model`: Model identifier (default: `gemini-3.8-flash`)
- `riposte.ghostText.enabled`: Enable inline code completion (default: `true`)
- `riposte.ghostText.debounceMs`: Completion delay in milliseconds (default: `250`)
- `riposte.rust.cargoPath`: Custom cargo path (default: `cargo`)
- `riposte.clang.clangdPath`: Custom clangd path (default: `clangd`)
